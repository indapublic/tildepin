Click a key.

Your keyboard as macOS ships it: ` sits on the extra key left of Z. Click it, or click the § key under Esc.

One key, one hand movement, every time.

An ISO keyboard has one more key than an ANSI one, and macOS puts `/~ on the extra key between Shift and Z. If your fingers learned to reach for the top-left corner, every backtick and every tilde is a small detour.

Two keycodes, swapped

No layout to install, no preferences to sync, nothing to configure. Install it once and forget it is there.

Just the two keys

The section key under Esc and the grave key left of Z trade virtual keycodes. Every other key, shortcut and modifier is untouched.

Every input source

Keycodes come before the layout is applied, so the swap works the same in U.S., British, German, Russian and Ukrainian — including in terminals and editors.

About 2 MB of memory

One small C program with no window, no menu bar icon and no settings. When you are not pressing a key, it does nothing at all.

Permission survives updates

Releases are signed with the same Developer ID and notarized by Apple, so macOS keeps the Accessibility permission across updates.

Install

Use one way or the other. Either way, TildePin starts at every login.

Homebrew Recommended

Installed this way, TildePin updates with the rest of your Homebrew packages.

Terminal
brew tap indapublic/tildepin https://github.com/indapublic/tildepin
brew trust --formula indapublic/tildepin/tildepin
brew install indapublic/tildepin/tildepin
brew services start tildepin

Update with brew upgrade tildepin. Remove with brew services stop tildepin and brew uninstall tildepin.

Before you install

TildePin does one thing in a blunt way. Here is what that means.

  • It needs AccessibilityOnly apps with this permission may see and rewrite key events. TildePin never stores what you type, never connects to the network and has no settings file. Its source is one C file.
  • Password fields keep the ISO keymacOS disables key taps while secure input is on, so in password fields the key under Esc still types §. That is the system protecting those fields, not something TildePin can lift.
  • Cmd+` follows the keymacOS cycles windows with the character, so the shortcut moves to the top-left key along with everything else. That is the ANSI position too.
  • Other keyboards need the tableIf your extra key sends a different keycode, make keys prints what every key sends, and a one-line entry in the REMAP table pairs it up.

Questions

Does it change my keyboard layout?

No. Your input sources stay as they are, switching between them works as before, and nothing is added to the input menu. TildePin only swaps two virtual keycodes on the way in.

How do I turn it off for a while?

Turn TildePin off in System Settings › General › Login Items, or run brew services stop tildepin. While it is off, both keys behave exactly as macOS ships them.

How do I remove it?

From Homebrew: brew services stop tildepin then brew uninstall tildepin. From the disk image: run /Applications/TildePin.app/Contents/MacOS/TildePin --unregister and move the app to the Trash. Then drop it from System Settings › Privacy & Security › Accessibility with the − button.

Why isn't it in the Mac App Store?

Apps in the Mac App Store must run in Apple's App Sandbox, and reading or rewriting key events needs the Accessibility permission, which sandboxed apps can't use for this. Utilities such as Rectangle and Karabiner are distributed outside the App Store too.

Something isn't right. What should I send?

The log at ~/Library/Logs/TildePin.log. Run open -R ~/Library/Logs/TildePin.log in Terminal to see it in Finder, then attach it to a new issue. It holds timestamps and the TildePin and macOS versions, nothing else. Mentioning what make keys prints for the two keys helps most.

How much does it cost?

Nothing. TildePin is free and open source under the MIT license.
